# 🌊 Gota a Gota

**Cada gota importa. Cada atitude faz a diferença!**

O **Gota a Gota** é um projeto desenvolvido para conscientizar as pessoas sobre a importância da água, os desafios relacionados à sua preservação e o impacto do consumo no nosso dia a dia.

A proposta é apresentar informações de forma visual, simples e acessível, incentivando pequenas mudanças de atitude para ajudar a preservar esse recurso tão importante para a vida.

## 🎯 Objetivo do projeto

- Conscientizar sobre a importância da água.
- Apresentar informações sobre a crise hídrica.
- Mostrar como o consumo doméstico influencia o uso da água.
- Explicar o conceito de água invisível.
- Incentivar hábitos mais conscientes e sustentáveis.

## 🛠️ Tecnologias utilizadas

- **Python:** funcionamento do servidor.
- **Flask:** criação e gerenciamento das rotas do site.
- **HTML5:** estrutura das páginas.
- **CSS3:** aparência e estilização do projeto.

## 📁 Estrutura do projeto

## 🚀 Como executar o projeto

1. Instale o Python no computador.
2. Abra o terminal na pasta do projeto.
3. Instale o Flask:

```bash
pip install flask
```

4. Execute o servidor:

```bash
python main.py
```

5. Abra o navegador e acesse:

```text
http://127.0.0.1:5000
```

## 💧 Por que esse projeto importa?

A água é essencial para a vida, mas nem sempre percebemos a quantidade que utilizamos diariamente. Entender nosso consumo é um passo importante para desenvolver hábitos mais responsáveis.

O Gota a Gota busca transformar informação em conscientização.
